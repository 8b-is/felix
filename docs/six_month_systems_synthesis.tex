\begin{abstract}
This paper synthesizes six months of systems engineering, formal methods, and applied discrete mathematics across the \texttt{8b-is}, \texttt{standardgalactic}, and \texttt{peterlodri-sec} repositories. We present a unified, mechanically verified software stack structured around four technical contributions: (1)~exact rational (\texttt{p/q}) and Base-243 balanced-ternary (\texttt{SPQT}) data representations achieving $99.06\%$ radix density with zero heap allocation; (2)~a capability-attenuated runtime (\texttt{PhoenixCapabilityAbiTable}) and linear type checker backed by 22 Ada~2022 / SPARK formal proof packages (\texttt{gnatprove --mode=check\_all}, 0~errors); (3)~verified discrete and spectral graph algorithms, including Harary structural balance over signed Laplacians $L^\sigma = D - A^\sigma$, exhaustive Ramsey $R(3,3)=6$ coloring verification, and a 6-step $Q_6$ statistical inference pipeline; and (4)~cross-platform systems integration spanning bare-metal ESP32-S3 DMA frames, \texttt{memnet} reference oracles, and automated E2E communication harnesses. The artifact is formatted to meet the reproducibility and formal assurance criteria of the \textbf{ACM Software System Award} and \textbf{CAV / POPL Distinguished Artifact} tracks.
\end{abstract}

\section{Balanced-Ternary Quantization and Exact Rational Scales}

Standard binary quantization of ternary weights $t \in \{-1, 0, +1\}$ using 2~bits per trit wastes $20.75\%$ of channel capacity ($\log_2(3) \approx 1.58496$ bits/trit). Across \texttt{memnet} and \texttt{felix-lang}, we pack 5 balanced trits into a single unsigned byte via the bijection:
\[
  \mathrm{pack}_5(t_0, t_1, t_2, t_3, t_4) = \sum_{j=0}^{4} (t_j + 1) \, 3^j \in \{0, \dots, 242\},
\]
achieving $\frac{5 \log_2 3}{8} = 99.06\%$ bit efficiency. For metadata and edge telemetry (\texttt{well\_signal\_spqt\_espnow.rs}, \texttt{well\_signal\_spqt\_spark.ads}), 14 signal trits plus a 15th $\mathbb{Z}_3$ parity trit $t_{14}$ satisfying $\sum_{i=0}^{14}(t_i + 1) \equiv 0 \pmod 3$ pack into exactly 3 bytes (\texttt{[239, 205, 238]} on Lap~1; \texttt{[239, 233, 104]} on Lap~2) and render to a 444-byte Markdown table inside a fixed \texttt{[u8; 512]} stack buffer (\texttt{StackMarkdownBuf}) with zero heap allocations.

\section{Linear Types, Capability Monotonicity, and SPARK Proofs}

The \texttt{felix} compiler and runtime enforce two complementary safety invariants:
\begin{enumerate}
  \item \textbf{Compile-Time Linearity}: Every \texttt{linear} binding in \texttt{felix-lang} must be consumed exactly once; double use or scope drop produces a static diagnostic before evaluation.
  \item \textbf{Hardware \& Runtime Capability Attenuation}: In \texttt{phoenix\_cap\_abi.rs} and \texttt{phoenix\_cap\_abi\_spark.ads}, 64-bit capability handles encode an 18-bit permission mask and ternary access mode $\tau_{\mathrm{perm}} \in \{-1, 0, +1\}$. Child capabilities derived via \texttt{CapDeriveSub} satisfy $\mathrm{Mask}_{\mathrm{child}} \subseteq \mathrm{Mask}_{\mathrm{parent}}$ and $\tau_{\mathrm{child}} \le \tau_{\mathrm{parent}}$ identically across POSIX \texttt{mmap}, WebAssembly linear memory, and ESP32-S3 DMA ring backends.
  \item \textbf{Cryptographic Webhook Verification}: \texttt{m8\_axum\_webhook\_server.rs} implements self-contained FIPS~180-4 SHA-256 and constant-time RFC~2104 HMAC-SHA256 verification across three payment webhook formats, minting read-only ($\tau_{\mathrm{perm}} = 0$) download tickets with one-time epoch revocation.
\end{enumerate}

\section{Signed Graph Laplacians, Combinatorics, and Statistical Inference}

\begin{enumerate}
  \item \textbf{Harary Signed Structural Balance (\texttt{signed\_ternary\_graph.rs}, \texttt{signed\_ternary\_graph\_spark.ads})}: Given a signed graph $G = (V, E, \sigma)$ with $\sigma_{uv} \in \{-1, 0, +1\}$, the signed Laplacian $L^\sigma = D - A^\sigma$ has Dirichlet energy
  \[
    x^T L^\sigma x = \sum_{(u,v) \in E} (x_u - \sigma_{uv} x_v)^2 = 4 \cdot |\mathrm{FrustratedEdges}(x)| \ge 0.
  \]
  We prove in SPARK that $x^T L^\sigma x = 0$ for $x \in \{-1, +1\}^N$ iff every cycle has sign product $+1$.
  \item \textbf{Discrete Percolation and Ramsey Verification (\texttt{erdos\_pqt\_omniversal.rs}, \texttt{erdos\_pqt\_spark.ads})}: Verifies geometrically damped ternary stride bounds ($D(d) \le 1.0$), the Erd\H{o}s--R\'enyi threshold $p_c = \frac{\ln N}{N} \approx 0.0004063$ ($N = 24{,}917$), Erd\H{o}s--Kac factor counts $\omega(n)$, and all $2^{15} = 32{,}768$ two-colorings of $K_6$ for Ramsey's theorem $R(3,3)=6$.
  \item \textbf{Six-Step $Q_6$ Statistical Inference (\texttt{self\_other\_hypercube\_inference.rs})}: Implements data collection, 6-bit $Q_6$ quantization, coherence recall, Pearson correlation $r$, and difference-in-means causal estimation.
\end{enumerate}
